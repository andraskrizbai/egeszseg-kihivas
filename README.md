# Egészség kihívás

Offline működő, telepíthető webapp (PWA) napi böjt (16 óra), alvás és kalória (2000-2200 kcal) követésére, kéthetes etapokban, játékos pontozással.

- Minden adat csak a saját böngésződben (localStorage) tárolódik, semmi nem kerül szerverre.
- Telepítés telefonra: nyisd meg az oldalt, majd Android/Chrome: menü, "Alkalmazás telepítése"; iPhone/Safari: Megosztás, "Főképernyőhöz adás".
- Az étel-kereső beépített listája offline is működik; az Open Food Facts keresés internetet igényel.
